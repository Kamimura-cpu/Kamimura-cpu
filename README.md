# 上村航我(Kamimura Koga)

長野大学 企業情報学部 田中ゼミ(2028年3月卒業見込み)。
大学在学中から、出張型のスマホ・PC修理/買取事業「**TechMate**」を運営しています(2025年度に事業化、売上700万円超)。

現場の困りごとを見つけて、技術とビジネスの両方から形にすることに取り組んでいます。

🔗 ポートフォリオ:https://kamimura-koga.vercel.app/
🔧 TechMate 公式サイト:https://techmate-repair.vercel.app/
